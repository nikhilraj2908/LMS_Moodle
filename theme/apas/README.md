<h3>APAS Theme – Installation Steps</h3>

<ul>
<li>Unzip the downloaded theme zip file to extract the folder <code>apas</code>.</li>
<li>Copy the folder <code>apas</code> into the <code>theme</code> directory of your Moodle installation.</li>
<li>Login as a Site Administrator.</li>
<li>Navigate to <b>Site administration → Notifications</b>.</li>
<li>On the “Plugins check” page, you will see the <b>APAS theme</b> listed.</li>
<li>Click <b>Upgrade Moodle database now</b>.</li>
<li>After installation, click <b>Continue</b> to access theme settings.</li>
<li>You can modify theme settings later anytime from the admin panel.</li>
</ul>

<h3>Steps to Set APAS as the Default Theme</h3>

<ul>
<li>Login as Site Administrator.</li>
<li>Go to <b>Site administration → Appearance → Themes → Theme selector</b>.</li>
<li>Click <b>Change theme</b> for the "Default" device type.</li>
<li>Select <b>APAS theme</b> and click <b>Use theme</b>.</li>
<li>Click <b>Continue</b> to apply your selection.</li>
<li>Congratulations! The APAS theme is now active.</li>
<li>For support or customization inquiries, contact: <a href="mailto:support@alogicdata.com">support@alogicdata.com</a></li>
</ul>
